# Wood Walls (and Roofs)

The Wood Walls (and Roofs) mod adds five (5) new wood wall (and roof) materials in a variety of styles.

_Looking for matching foundations? Check out: https://ficsit.app/mod/WoodFoundations_

## Features

### Five (5) new wall (and roof) materials
  - __Wood (Pine):__ Unlocked automatically when walls/roofs are unlocked
  - __Redwood__, __Walnut__, __Light__, and __Dark:__ Purchasable in the Awesome Shop for 2 Tickets each
  - Build Cost: All wood wall (and roof) varieties __require 2 Wood per item__ to build.
    - _If you don't wish to gather wood, you can enable an alternate cost of 5 Concrete per wall (and roof) in the Mod's Savegame settings (Menu > Mod Save Game Settings > Wood Walls)_
  - Usable on all 27 vanilla wall shapes, and all 10 vanilla roof shapes

### Complete Vanilla Material Customizer Functionality
  - Each Wood Material, once unlocked, can be applied with the customizer like any other wall (and roof) material (i.e. concrete, steel, etc.), or they can be built directly as normal via the build gun menu.
  - Further, you can use the customizer to turn wood walls (and roofs) back into any vanilla wall (or roof).
  - Buying wall (and roof) sets from the Awesome shop will also unlock the relevant wood versions for any wood varieties you have unlocked (i.e. same beahvior as default customizer materials like Concrete and Steel). 
  - __TL;DR: The wood materials work exactly like the vanilla wall (and roof) materials__

### Coloring
  - Color swatches: I've setup the textures so that the Primary color has a 30% weighted affect on the albedo of the wood, but won't 'paint' the wood that color. 

### Performance
  - I've taken great care to ensure these Wood Walls (and Roofs) are constructed the exact same way vanilla objects are built. All textures are implemented as Material Instances of base-game materials to prevent unnecessary shader overhead, and all buildables fully utilize the game's native Abstract Instance system.
